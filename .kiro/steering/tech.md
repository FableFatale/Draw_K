# 技术栈

## 前端技术
- **HTML5/CSS3/JavaScript** - 基础web技术
- **图表库**: 
  - ECharts - 推荐用于K线图渲染
  - 或 Chart.js - 轻量级选择
  - 或 D3.js - 高度定制化需求

## 构建工具
- **Vite** - 现代前端构建工具（推荐）
- 或 **Webpack** - 传统构建工具
- **npm/yarn** - 包管理器

## 开发依赖
- **ESLint** - 代码规范检查
- **Prettier** - 代码格式化

## 常用命令

### 开发环境
```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```

### 代码质量
```bash
# 代码检查
npm run lint

# 代码格式化
npm run format
```

## 技术约定
- 使用ES6+语法
- 组件化开发模式
- 响应式设计
- 支持现代浏览器
